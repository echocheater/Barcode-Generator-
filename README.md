Barcode Label Generator
​Aplikasi web ringan berbasis HTML, JavaScript, dan library JsBarcode untuk merender, mengelola, dan mencetak label barcode dalam tata letak grid. Dirancang agar responsif dan mudah diintegrasikan langsung ke dalam bot Telegram sebagai Telegram Mini App.
​Fitur Utama
​Grid Label Interaktif: Menyediakan 40 kotak label yang dapat diisi nama, harga, dan kode secara mandiri atau diterapkan ke seluruh kotak sekaligus.
​Multi-Format Barcode: Mendukung berbagai standar barcode populer seperti CODE128, EAN13, EAN8, UPCA, CODE39, ITF14, dan Codabar.
​Ekspor Data JSON: Mengunduh kumpulan data label yang telah diisi ke dalam format file .json.
​Cetak PDF: Dioptimalkan untuk proses cetak langsung ke printer fisik maupun penyimpanan dokumen PDF melalui browser.
​Integrasi Telegram Mini App: Dilengkapi dukungan Telegram Web App SDK agar dapat dibuka langsung di dalam antarmuka aplikasi Telegram.
​Cara Penggunaan
​Clone atau unduh repositori ini ke perangkat Anda.
​Buka file index.html menggunakan browser modern, atau aktifkan GitHub Pages di pengaturan repositori untuk mendapatkan tautan HTTPS publik.
​Masukkan tautan HTTPS tersebut ke BotFather di Telegram untuk menghubungkannya sebagai tombol Menu Web App pada bot Anda.
